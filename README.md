## Getting Started
>>>>>>> e504d31d4dda06cc92f1f5db5470927140c1ec08

Install Git and a Java JDK compatible with the project's Gradle configuration, then clone the repository:

```bash
git clone https://github.com/an-nguyen06/jpacman-testing.git
cd jpacman-testing/jpacman
```

Run these commands from the `jpacman` directory:

| Task | macOS / Linux | Windows PowerShell |
| --- | --- | --- |
| Run tests | `./gradlew test` | `.\gradlew.bat test` |
| Tests and static analysis | `./gradlew check` | `.\gradlew.bat check` |
| Launch the game | `./gradlew run` | `.\gradlew.bat run` |

Test reports are generated at `build/reports/tests/test/index.html` within `jpacman/`.
